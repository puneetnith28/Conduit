The safety loop
Every line an agent prints is read twice.
1. By pattern — 23 regexes, in-process, no model call. Catches a prompt waiting for a human, or a command expensive to undo.
2. By the Supervisor — batched, debounced 10s, at most once per agent per 20s.
A gate freezes the agent until you answer. The Supervisor can only propose; every decision is appended to audit.jsonl.
